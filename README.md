# Digital Bookshelf

A PWA to catalog your media. **Phase 2** adds Dexie Cloud sync with email (OTP) sign-in, an iOS-optimized standalone viewport, and Vercel deployment. Phase 1 (games + music catalog) is unchanged feature-wise.

## Tech Stack
- Svelte 5 (+ runes) + Vite
- Tailwind CSS v4
- Dexie + Dexie Cloud (IndexedDB sync, email OTP auth)
- PWA (vite-plugin-pwa), deployed on Vercel

## Run locally
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview  # preview production build (service worker active)
```

`dexie-cloud.json` and `dexie-cloud.key` in the project root (gitignored) point the app at the cloud database. For CI/builds where those files don't exist, set the environment variable `VITE_DEXIE_CLOUD_URL=https://<your-db>.dexie.cloud` (see `.env.example`).

## Running (Phase 2)
- **Sign-in**: Dexie Cloud email OTP with the app's own simpler login screen (email → OTP code; the field accepts both numeric and alphanumeric codes).
- **Sync**: local writes sync to Dexie Cloud in the background; the app works fully offline as a PWA.
- **Sign out**: link in the sidebar (Dexie Cloud asks for confirmation if there are unsynced changes).
- **iOS PWA** (390 × 844 target): standalone display, black-translucent status bar with safe-area insets, no page-level scrolling (each view scrolls internally), portrait orientation manifest, real PNG icons (`public/pwa-*.png`, generated by `node scripts/generate-icons.mjs`).

## Deployment (Vercel)
1. Import the repo into Vercel (Vite is auto-detected; build = `npm run build`, output = `dist/`).
2. In Vercel → Settings → Environment Variables add `VITE_DEXIE_CLOUD_URL` = the `dbUrl` from `dexie-cloud.json`.
3. Whitelist your production origin for the cloud database (Dexie Cloud blocks unlisted origins):
   ```bash
   npx dexie-cloud whitelist https://<your-app>.vercel.app
   # already whitelisted locally: http://localhost:5173
   ```
4. Add to iOS home screen for the standalone PWA view.

## Project layout
```
src/
  App.svelte                       hash-routing shell + fixed-height (no-scroll) app frame
  app.css                          Tailwind theme, dark variant, iOS no-scroll + hidden scrollbars
  lib/
    db.js                          Dexie schema, Dexie Cloud config, status metadata, sorting, CRUD
    store.svelte.js                reactive live queries + dark mode (runes)
    components/
      Sidebar.svelte               nav, sign-out, collapsible rail, dark-mode switch
      LoginGui.svelte              custom Dexie Cloud login/OTP dialog
      Landing.svelte  MediaPage.svelte
      RecordCard.svelte  RecordModal.svelte  SongsEditor.svelte
scripts/
  generate-icons.mjs               regenerates PNG PWA icons
```
